# Student Progress Tracker

## Description
A web-based platform designed to help students and educators monitor academic performance, track assignments, and analyze learning progress.

## Technologies Used
- HTML5
- CSS3
- Vanilla JavaScript

## How to Run
1. Clone or download this repository to your local machine.
2. Open `index.html` directly in any standard web browser (Chrome, Firefox, Safari, Edge).
