# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] — 2024-01-30

### Added

- Authentication with JWT mock, session persistence, and route protection
- Student dashboard with profile, course progress, and grades
- Interactive charts (bar, doughnut, line) using Chart.js
- Course cards with progress bars and status badges
- Mock API integration with MSW for testing
- Error handling with toast notifications, error boundaries, and retry
- Responsive layout with mobile drawer navigation
- Dark mode theme support
- Accessibility features (ARIA, keyboard nav, screen reader announcements)
- Deployment configuration (Vercel, GitHub Pages)
- CI/CD pipeline (lint, test, build, deploy)
